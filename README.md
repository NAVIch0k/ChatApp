# Todo List (React + Redux Toolkit + TypeScript)

Простое веб‑приложение для управления задачами.

## Возможности
- Добавление задач
- Отметка выполнения
- Удаление
- Редактирование
- Фильтрация (все / активные / выполненные)
- Перетаскивание задач (drag‑and‑drop)
- Сохранение в `localStorage`

## Стек
- React + TypeScript
- Redux Toolkit
- @dnd-kit
- SCSS modules + Tailwind

## Установка и запуск
```bash
npm install
npm run dev
```

## Скрипты
- `npm run dev` — запуск dev сервера
- `npm run build` — сборка
- `npm run preview` — предпросмотр сборки
- `npm run format` — форматирование Prettier
